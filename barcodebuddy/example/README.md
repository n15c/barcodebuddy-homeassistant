# Beispiele

- `grabInput.sh` – liest Barcodes von einem Scanner bzw. einer Tastatur und übergibt sie an Barcode Buddy.
  Im Home-Assistant-Add-on startet der Dienst `grabber` dieses Skript (Option „Barcodescanner anbinden“).
- `defaultBarcodes/` – die Standard-Barcodes für die Modi (Kaufen, Verbrauchen, Öffnen, …) zum Ausdrucken.
